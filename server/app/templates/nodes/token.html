Install on the Raspberry Pi

  1. In /etc/temperature-node/config.yaml, set node.id: {{ node.uid }} and server.url to this server's address, e.g. {{ request.host_url.rstrip('/') }}.
  2. Put the token in /etc/temperature-node/node.env (readable only by root and the service):
